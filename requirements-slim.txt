# Deployment profile without the transformer stack.
#
# torch, transformers and en_core_web_trf are three quarters of the full
# install and exist only for BERT fine-tuning and transformer NER. Neither is
# usable on a free CPU host: fine-tuning needs a GPU, and the transformer NER
# model takes minutes to load. Omitting them takes the install from about
# 1,729 MB to about 415 MB.
#
# Named entity recognition falls back to en_core_web_sm automatically, and the
# interface hides BERT fine-tuning when this profile is in use.
#
# The full requirements.txt remains the profile for local and container use.
